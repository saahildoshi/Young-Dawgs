# Authentic matched LLM revision experiment

Four independent ordinary-ChatGPT conversations, two MF and two NF, one returned module each, no researcher repairs or additional model attempts. All original code bytes, complete code-only responses, submission URLs and capture receipts are preserved. The fourth source was recovered from its existing completed chat after display reconnection; the earlier failure checkpoint remains archived.

All trials used the same visible High configuration. The exact model/backend version, token count, cost, account-memory and routing conditions are unavailable. Fresh initial chats were outside the project; personalization was not independently controlled. No privacy settings were changed.
