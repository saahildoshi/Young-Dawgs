# Completed P3 + F1 real microscopy pilot

The registered ordinary-ChatGPT experiment is complete: 12 independent parent scripts (two per family and condition), four paired C revisions, 16 actual model interactions and 320 valid generated images. Each of 16 unedited source versions produced ten development images (seeds 100–109) and ten held-out images (seeds 0–9), with exact repeat-seed determinism and zero execution failures. All sources were frozen in commit 456c682 before any held-out execution. No subsequent model feedback or manual source repairs occurred. All 12 chats are confirmed in Pipeline Tests after a browser reload; audit/CHAT_ORGANIZATION.json records their exact conversation IDs and project URLs.

RESULTS.md contains per-script, condition-level and paired quantitative tables plus fixed-seed reference/generated figures. Condition means average script means equally; seeds and revisions are not extra independent trials. On held-out seeds, supplied-descriptor mean error decreased from A to B for P3 (0.1410 to 0.02530) and F1 (0.2617 to 0.1736). Withheld-descriptor error also decreased on average (P3: 0.09927 to 0.08332; F1: 0.2623 to 0.1760). These are descriptive comparisons with only two independent scripts per cell. F1_B_01 and F1_B_02 differ substantially; this pilot does not establish reliable improvement across models or materials.

All four feedback pairs reduced supplied-descriptor error on held-out seeds. Withheld-descriptor error improved in three pairs and worsened in P3_C_01. Every source produced ten distinct arrays per native phase within each partition. This diversity diagnostic does not prove complete stochastic independence or physical fidelity. C receives an extra model interaction and some revisions increased internal candidate-search effort, so this pilot does not isolate a causal feedback-only benefit.
