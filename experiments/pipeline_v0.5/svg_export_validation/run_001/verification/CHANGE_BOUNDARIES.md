# v0.5D1 change boundaries

The initial inventory contains 8,507 preexisting project files, including
earlier uncommitted local changes. The earlier C.1 initial inventory and
addition ledger authenticated 8,506 historical paths; its self-excluded ledger
is also covered by the current initial inventory. Final preservation is a
byte-level comparison against this current inventory, not a Git reset.

Only new source, tests, D1 documentation, analysis scripts and the new
svg_export_validation/run_001 experiment are added. Existing generators,
native renderers, evaluator, geometry conversion/manifold/simplification,
source masks, WKBs, manifests and historical reports/statuses remain unchanged.

The final code/protocol freeze precedes all four real SVG exports. Subsequent
edits concern reporting, layout and handoff only. Source geometry and numerical
criteria were not tuned after the real results. Strict parsers retain failures;
there is no fallback to original coordinates or geometry repair.

Synthetic controls use analytic polygons and the existing A1 routine solely to
construct a deterministic test of a known repaired contact. No procedural
research microstructure or new parameter point was generated. The real study
loads only the registered saved G1/G2/G3 inputs.

SVG output is research-only 2D interchange. No DXF/STEP/STL, CAD kernel, 3D,
meshing, FEM, physical-scale assignment, mechanical prediction or manufacturing
functionality is added. Successful serialization does not resolve historical
small-pore fidelity or finite changed-region feature-audit limitations.
