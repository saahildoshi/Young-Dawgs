I developed and test-ran a fully procedural generator. It uses a warped, anisotropic Poisson/Voronoi ridge construction: blue-noise-like sites establish the pore scale, smooth coordinate warping adds tortuosity, the nearest/second-nearest distance gap creates the branching vein network, and a correlated width field introduces strut-thickness variation. Several stochastic candidates are generated for each seed and scored against the supplied thickness, pore-size, connectivity, and two-point-correlation descriptors.

In a full 20-seed test, every sample had solid fraction **0.3946990967**, horizontal and vertical percolation, and one dominant 4-connected network. Mean strut thicknesses were about **6.53–6.67 px**, the 10th-percentile thickness was **4 px** throughout, and median pore diameters were about **16.1–17.2 px**. The generated networks were fully connected in that test, giving largest-component fraction 1.0 rather than 0.992384, while satisfying the stronger load-bearing connectivity requirement.

The main adjustable controls are `N_SITES_RANGE` for pore scale, `MIN_SITE_DISTANCE_RANGE` for pore-size regularity, `ANISOTROPY_RANGE` for directional organization, `WARP_AMPLITUDE_RANGE` / `WARP_SIGMA_RANGE` for vein tortuosity, `WIDTH_MODULATION_RANGE` for thickness variation, and `CANDIDATES_PER_SEED` for statistical matching quality.

[Download the complete self-contained Python script](sandbox:/mnt/data/procedural_metamaterial_generator.py)

It requires only NumPy, SciPy, scikit-image, and Pillow. Running:

```bash
python procedural_metamaterial_generator.py
```

creates `generated_microstructures/` containing `microstructure_seed_00.png/.npy` through `microstructure_seed_19.png/.npy`. The NPY arrays are `uint8` with **solid = 1** and **void = 0**. The script never reads or accesses the supplied reference image.
