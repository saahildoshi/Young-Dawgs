# Repository instructions

After every coherent repository change, run appropriate validation, review the diff, and make a descriptive Git commit. Never silently leave completed tracked changes uncommitted. Do not stage unrelated user changes.

Inspect status, branch and HEAD before work. Record each completed commit and any
remaining changes in the final response. Do not push, rewrite history, delete
branches, or commit secrets, solver databases, caches or large generated binaries.

Current priority: Pipeline v0.6, actual 2D meshing and contact-enabled ANSYS
compression. Preserve generators, frozen evaluator v1.1, canonical geometries,
historical runs and scientific HOLD decisions. Do not implement 3D workflows or
autonomous LLM optimization. ANSYS results require a real, evidenced solver run;
input-deck generation and synthetic controls never establish solver acceptance.
